The Megalith Highway

Portugal, Galicia, Brittany, Ireland, Wales, Orkney and Scandinavia built recognisably the same great stone tombs. I put {{data.megaliths|int}} megalithic monuments on one map and tested, three honest ways, whether the idea travelled by sea.
